# AI Tools Used in AgroMind

This document describes how AI tools supported the research, planning,
development, and media production of **AgroMind**, a NASA-data-powered
crop-rotation decision-support project developed by Team Pioneers.

## AI Tools and Their Contributions

  -----------------------------------------------------------------------
  AI tool                             How we used it
  ----------------------------------- -----------------------------------
  **Claude (Anthropic)**              Our primary AI assistant for
                                      brainstorming, shaping project
                                      ideas, coding assistance,
                                      generating and refining prompts,
                                      and supporting video-editing
                                      workflows.

  **ChatGPT (OpenAI)**                Assisted with project research,
                                      exploring NASA datasets, organizing
                                      technical information, refining
                                      documentation, and solving
                                      development-related questions.

  **Google Gemini**                   Supported agricultural research,
                                      exploring use cases, and developing
                                      project descriptions and other
                                      content.

  **Google AI Studio**                Used to create AI-generated
                                      animated video content for the
                                      project presentation.
  -----------------------------------------------------------------------

## Information Shared with AI Tools

Depending on the task, we provided project concepts and requirements,
NASA dataset documentation, agricultural information, crop-rotation
concepts, technical questions, and prompts for media generation.

## AI Use in the AgroMind Concept

AgroMind is designed to present scientific analysis in language that
farmers can understand. AI-assisted explanations may help communicate
crop-rotation comparisons, potential risks, and supporting evidence. The
underlying scientific calculations and data analysis are intended to be
performed by the system's defined methods and code---not invented by a
generative AI model.

> **Transparency note:** The AI tools listed above supported the team's
> project-development workflow. The description of farmer-friendly AI
> explanations refers to the intended AgroMind functionality; it should
> not be interpreted as a claim that every planned AI feature is already
> implemented.
