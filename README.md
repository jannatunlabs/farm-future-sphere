# AgroMind 

Build a world-class frontend for a NASA Space Apps hackathon project called TerraFarm AI.

Tagline: “See the Future of Your Farm.”

Create a premium futuristic climate-tech website that helps farmers analyze their land, discover suitable crops, understand climate risks, and explore future farming scenarios.

Main flow

Home → Select Land → Analyze → Land Intelligence → Crop Advisor → Profit Simulator → Risk Center → Future Simulation → Scenario Lab

Design

NASA + Google Earth + premium AI dashboard aesthetic

Dark space-inspired UI

Deep navy/black background

White text with cyan and agriculture-green accents

Glassmorphism

Beautiful maps

Interactive charts

Smooth animations

Premium typography

Fully responsive mobile design

NOT a generic admin dashboard

Create a realistic Demo Farm with pre-filled data so judges can experience the entire product immediately.

Important

For this build, focus ONLY on the frontend and user experience.

Use realistic DEMO DATA. Do not waste credits implementing NASA APIs, Supabase, authentication or complex backend systems yet.

Create all pages, navigation, charts, maps, cards, interactions, loading animations and responsive layouts so the project already feels like a complete hackathon product.

Make it visually spectacular, polished, scientific and presentation-ready.
